4. COMPLETE DEPENDENCY INSTALLATION GUIDE
--------------------------------------------------------------------------------
To setup this project from scratch on a new machine:

Step 1: Install Python 3.12.1 (64-bit) from https://www.python.org/
        (Make sure to check 'Add python.exe to PATH' during installation)

Step 2: Create and activate virtual environment:
        python -m venv venv
        venv\Scripts\activate

Step 3: Install pre-built dlib wheel (included in repository root):
        pip install dlib-19.24.99-cp312-cp312-win_amd64.whl

Step 4: Install all required project packages:
        pip install -r requirements.txt

Step 5: Run Desktop Application:
        python desktop_app.py
        (or execute: run.bat)

Step 6: Run Web Dashboard (Optional):
        streamlit run app.py
        (or execute: run_web.bat)
